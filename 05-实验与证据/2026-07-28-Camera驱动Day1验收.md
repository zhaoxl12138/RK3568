## 操作目的

## 原始命令

```bash
uname -a
v4l2-ctl --list-devices
v4l2-ctl -d /dev/video0 --all
media-ctl -p
dmesg | grep -Ei 'imx415|rkisp|csi|v4l2|media|camera'
```

板端是 Buildroot 环境，检索日志使用 `grep`；本记录不假设板端安装了 `rg`。

## 可以证明

- `EVID-20260728-CAMERA-DAY1` 可以证明本次环境中 IMX415 驱动实例完成读 ID，D-PHY、CSI、ISP 的异步绑定和 Media link 已建立。
- 查询时 Sensor 侧为 RAW10 Bayer，ISP / video node 处于不同的数据表示层；`/dev/video0` 查询到 NV12 多平面内存格式。
- `3840×2160` 是 2026-07-28 查询到的当时状态，不是跨启动、跨日期的永久默认值。
- 日志中的曝光设置说明驱动曾进入工作配置流程，但不单独等价于成功接收用户态帧。
