## 当前复现命令

板端启动：

```bash
cd /userdata/aidemo/06_yolov5_python
SHOW_MIPI=1 FRAMES=0 ./start_yolov5_hls_demo.sh
```

Windows 拉流：

```powershell
ffplay http://192.168.0.230/hls/yolo.m3u8
```

当前默认方向：

```text
ROTATE=none
DISPLAY_ROTATE=ccw
STREAM_ROTATE=ccw
```
