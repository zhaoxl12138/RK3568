格式层级

名称所在层级本基线的解释
SGBRG10_1X10Sensor / subdev Media busIMX415 RAW10 Bayer 在 pad/link 上的总线表示
YUYV8_2X8ISP source pad 一侧的 Media bus format描述 subdev pad 之间的总线格式；仓库未保留带日期的完整原始输出，因此不把它绑定为 2026-07-28 的永久“当前格式”
NV12/dev/video0 video node memory format描述用户态缓冲区中的 YUV 4:2:0 多平面布局；它不能替代 Media bus format

因此，看到 YUYV8_2X8 与 NV12 并不构成冲突：前者是 Media bus / pad 层，后者是 video node memory / buffer 层。任何页面写“当前格式”时必须同时写日期、节点和命令。
