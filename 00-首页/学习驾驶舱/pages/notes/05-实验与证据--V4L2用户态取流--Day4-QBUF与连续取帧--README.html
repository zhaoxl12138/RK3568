在 Obsidian 中打开

Day3 只是准备好了 Buffer 和用户地址。Day4 第一次让 Camera 真正向这些 Buffer 写入图像。

今天只抓住四个动作：

QBUF
→ 应用把空 Buffer 交给驱动

STREAMON
→ 启动 Capture 队列及上游 Camera 管线

poll + DQBUF
→ 等到一帧完成，并把 DONE Buffer 取回应用

再次 QBUF
→ 应用处理完成后归还 Buffer，让驱动继续写下一帧

Buffer 所有权循环：

应用持有 Buffer
      │ QBUF：交给驱动
      ▼
QUEUED → ACTIVE → DONE
                    │ DQBUF：交还应用
                    ▼
               应用读取本帧
                    │ 再次 QBUF
                    └────────────→ 下一轮
