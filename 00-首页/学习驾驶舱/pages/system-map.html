按证据定位，不从应用层反猜底层

没有识别到 Sensor

先查原理图、DTS、I2C 地址、上电时序、时钟、RESET/PDN 和 Sensor ID。

识别成功但没有图像

继续查 endpoint、lane 数、频率、D-PHY、CSI-2、RKISP 和 Media Graph。

有节点但应用抓帧失败

再查 video node、格式、分辨率、stride、VB2 buffer 和 stream on。

大白话

两条支线，最后汇合

I2C 控制链让 IMX415 能上电、读 ID、接收配置；MIPI 数据链把 RAW10 送进 D-PHY、CSI 和 RKISP。两条链都正常才可能抓到帧。

证据边界

每条证据只证明一层

Detected imx415 id 不能证明 MIPI 有数据；media-ctl -p 的 Link 不能证明帧稳定；实际抓帧才证明数据到达用户态。
