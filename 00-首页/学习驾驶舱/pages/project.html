关键故障

按层定位

Sensor ID 失败：先查供电、xvclk、RESET/PDN、I2C 地址和引脚复用。
ID 成功但无图：转查 lane 配置、endpoint、D-PHY/CSI 错误、Media link、格式传播和 RKISP。
有 video 节点但抓帧失败：继续查格式协商、buffer queue、STREAMON 和数据错误，不能倒推 Sensor 已正常出流。

可复现步骤

从声明到数据

  1. 确认原理图的供电、时钟、控制信号和 CSI Lane。
  2. 核对 DTS 的 I2C 节点、GPIO、clock、endpoint 和 data-lanes。
  3. 用 sysfs 与 dmesg 验证 client、驱动绑定、probe 和 Sensor ID。
  4. 用 media-ctl -p 验证 entity、pad、link 与格式。
  5. 用 v4l2-ctl 完成格式查询、STREAMON 和带哈希抓帧。
