# V4L2 用户态编程一周执行计划

> 前置源码学习：[[02-源码陪读/08-V4L2用户态取流/00-源码陪读索引|08 V4L2/VB2 用户态取流源码陪读]]  
> 课程入口：[[08-V4L2用户态取流]]  
> 本周原则：停止扩展内核源码，只完成用户态抓帧闭环。

## 本周唯一目标

在 RK3568 + IMX415 上独立完成：

```text
IMX415
→ RKISP mainpath
→ /dev/video0
→ V4L2 ioctl
→ MMAP Buffer
→ 连续抓取 100 帧
→ 保存 NV12
→ 转换并确认图像
```

最终工程：

```text
v4l2_capture/
├─ main.c
├─ v4l2_capture.c
├─ v4l2_capture.h
├─ Makefile
├─ README.md
├─ output/
│  ├─ frame_000.nv12
│  └─ frame_000.png
└─ evidence/
   ├─ querycap.txt
   ├─ formats.txt
   ├─ capture.log
   └─ fps-result.txt
```

### 故障判断

| 现象 | 优先检查 |
|---|---|
| 全黑 | 曝光、Sensor 输出、保存长度 |
| 绿屏或偏色 | NV12/NV21、UV 顺序 |
| 图像错位 | stride、`bytesperline` |
| 撕裂或截断 | Plane 长度、尺寸、`bytesused` |
