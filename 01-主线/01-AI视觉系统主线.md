# AI 视觉系统主线

## 当前已验证项目基线

当前可复现基线是出厂 Buildroot 4.19 环境上的 **YOLOv5 RKNN Python MVP**。YOLOv8n、C++ 工程化与 Linux 5.10 都属于后续升级方向，不写入当前完成口径。

## 端到端数据流

```text
IMX415 Camera
-> RKISP / V4L2
-> 显式 GStreamer pipeline
-> OpenCV BGR Mat
-> 前处理
-> YOLOv5 RKNN / NPU
-> 后处理与结果叠加
-> 结果帧
   ├─ 本地显示分支 -> MIPI Display
   └─ 网络输出分支 -> encoder -> RTMP/HLS -> Windows player
```

## 阶段依赖图

```text
阶段0 系统全景
-> 阶段1 板端验机

-> 阶段3 NV12 单帧采集

```

## 模块职责摘要

| 模块 | 核心职责 | 交付给下一模块 |
|---|---|---|
| Camera / ISP / V4L2 | 形成稳定、格式明确的采集帧 | V4L2 buffer |
| GStreamer / OpenCV | 协商格式并交付程序可处理图像 | BGR Mat |
| 前处理 | 对齐模型尺寸、颜色、布局与量化要求 | 输入 tensor |
| RKNN Runtime / NPU | 执行模型计算 | 输出 tensor |
| 后处理 / 叠加 | 解码、筛选、NMS、坐标回映与绘制 | 结果帧 |
| Display | 消费结果帧并完成板端显示 | 本地画面 |
| Encoder / RTMP / HLS | 编码并分发结果帧 | 网络播放流 |
