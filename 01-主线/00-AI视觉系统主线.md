# 00-AI视觉系统主线

本文件是路线层唯一主线。

它只回答三个问题：

- 方向是什么。
- 分几个阶段走。
- 每个阶段涉及哪些技术栈。

## 总路线

目标不是转纯算法，也不是做大模型，而是把已有的 Camera、Linux、视频流经验升级成 AI 视觉系统工程能力。

系统闭环：

Camera -> V4L2/GStreamer -> OpenCV -> YOLOv8n -> NCNN/RKNN -> RTSP/RTMP -> Linux部署

## 阶段任务

### 阶段1：Camera 出图

目标：确认 IMX415 在 RK3568 上能稳定出图。

任务：

- 枚举 `/dev/video*`
- 使用 `v4l2-ctl` 查看格式和分辨率
- 理解 `/dev/video0`、`NV12`、分辨率、采集流程
- 对照官方 Camera 应用开发手册

当前状态：正在进行。

### 阶段2：OpenCV 处理

目标：把 Camera 帧送入 OpenCV。

任务：

- OpenCV 读取摄像头
- 保存单帧图片
- 理解 BGR、RGB、NV12、YUV 转换
- 为后续 YOLO 输入做预处理

当前状态：下一阶段。

### 阶段3：YOLOv8n ONNX

目标：先在 CPU 或通用推理框架中跑通 YOLOv8n。

任务：

- 导出 YOLOv8n ONNX
- 单张图片推理
- Camera 实时推理
- 画框和类别输出

当前状态：后置。

### 阶段4：NCNN / RKNN

目标：把模型部署到 RK3568 的边缘推理链路。

任务：

- ONNX 转 NCNN
- ONNX 转 RKNN
- 跑官方 AI 例程
- 对比 CPU/NPU FPS

当前状态：后置。

### 阶段5：RTSP / RTMP 推流

目标：输出带检测结果的视频流。

任务：

- 先参考资料中的 RTMP 推流链路
- 后续扩展 RTSP
- 封装采集线程、推理线程、推流线程
- 输出项目 README 和演示截图

当前状态：后置。

## 技术栈地图

### Camera

- MIPI CSI
- V4L2
- `v4l2-ctl`
- GStreamer
- OpenCV VideoCapture

### 图像处理

- YUV
- NV12
- RGB/BGR
- resize
- crop
- color convert

### AI 推理

- YOLOv8n
- ONNX
- ONNX Runtime
- OpenCV DNN
- NCNN
- RKNN Toolkit
- RKNN Runtime

### 多媒体推流

- GStreamer pipeline
- FFmpeg
- H.264/H.265 编码
- RTSP
- RTMP

### Linux 部署

- Buildroot
- 交叉编译
- 静态 IP
- SSH
- NFS/TFTP/FTP/Samba
- 自启动程序

## 不作为当前重点

- LLM
- Agent
- RAG
- Transformer 原理
- CUDA 深度优化
- Android 应用
- Qt UI
- OpenHarmony
