# 00-AI视觉系统主线

本文件是路线层主线，只回答三个问题：

- 方向是什么。
- 分几个阶段走。
- 当前停在哪个阶段。

具体从零学习步骤见 [[01-从零到Python MVP学习路线|01-主线 / 从零到Python MVP学习路线]]。

## 方向定位

目标不是转纯算法，也不是做大模型，而是把已有的 Camera、Linux、视频流经验升级成 AI 视觉系统工程能力。

岗位定位：

```text
懂 AI 部署的 Linux 多媒体工程师
```

系统闭环：

```text
Camera -> V4L2/GStreamer -> OpenCV -> RKNN/NCNN -> MIPI/RTSP/RTMP -> Linux部署
```

## 当前已跑通闭环

当前实际跑通的是 Python MVP：

```text
IMX415 MIPI Camera
-> RKISP / V4L2
-> GStreamer
-> OpenCV
-> YOLOv5 RKNN / NPU
-> MIPI屏显示
-> RTMP/HLS
-> Windows ffplay 拉流
```

当前项目名：

```text
RK3568 YOLOv5 RKNN AI Camera Python MVP
```

说明：

```text
YOLOv8n 仍是后续目标。
当前 4.19 出厂系统下，官方资料直接可复用的是 YOLOv5 RKNN。
```
