## 已验证链路（项目版本基线）

已验证的 Python MVP 链路：

```text
IMX415 MIPI Camera
-> RKISP / V4L2
-> GStreamer
-> OpenCV
-> YOLOv5 RKNN / NPU
-> MIPI 屏显示
-> RTMP/HLS
-> Windows ffplay 拉流
```

稳定基线是 `RK3568 YOLOv5 RKNN AI Camera Python MVP`；YOLOv8n、C++ 工程化和 Linux 5.10 均不代表已完成版本。
