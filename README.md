# RK3568 AI视觉学习复盘仓库

这是 RK3568 AI Camera 项目的 Obsidian 学习与实验复盘库，不是正式代码仓库。

## 当前成果

已验证的 Python MVP 链路：

```text
IMX415 MIPI Camera
-> RKISP / V4L2
-> GStreamer
-> OpenCV
-> YOLOv5 RKNN / NPU
-> MIPI 屏显示
-> RTMP/HLS
-> Windows ffplay 拉流
```

当前基线是 `RK3568 YOLOv5 RKNN AI Camera Python MVP`；YOLOv8n 是后续目标，不代表当前完成版本。
