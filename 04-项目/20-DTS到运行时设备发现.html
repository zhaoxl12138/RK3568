当前 阶段 05 · V4L2 Subdev

DTS → OF → 运行时设备对象

DTS 不是驱动调用脚本。它先变成内核中的设备树节点；不同父控制器再把节点翻译为 platform_device 或 i2c_client，endpoint 则保留为后续 Camera 拓扑的连接条件。

实线：直接调用 / 控制流虚线：赋值 / 对象关联 / 数据依赖

大白话

DTS 像硬件清单。Platform 框架把“焊死在 SoC 里的设备”建成 platform_device；I2C Core 把 I2C4 下面的 IMX415 建成 client；endpoint 只是把“未来该接谁”记下来。

证据边界

/sys/firmware/devicetree/base 证明 DTB 节点存在；/sys/bus/i2c/devices/4-001a-1 证明 client 已创建。它们都不能单独证明 probe、Sensor ID 或出图成功。

面试表达

DTS 不直接调用驱动。OF Core 先建立 device_node；Platform 或 I2C 子系统根据节点类型创建设备对象，之后 Driver Core 才匹配并回调 probe；endpoint 留给 Media/V4L2 解析拓扑。
