4. 关键子系统深度拆解

Camera 采集子系统 — ISP2.1 + VICAP

来源: RK3568 TRM Part2 Ch.12 (ISP), Ch.27 (CSI Host), Ch.28 (DPHY); Linux mainline rkisp1 + rkcif drivers (Michael Riesch, v15 Nov 2025)
ISP 2.1内置 MIPI CSI-2 Host，独立于 VICAP。支持 3A (AF/AE/AWB)、3DNR、HDR、LSC、DPC。虚拟 sditf 链路连接 VICAP。
VICAP独立采集单元，DVP 并行 + MIPI CSI-2 双输入。Ping-pong DMA 缓冲。在 RK356X 上与 ISP 为独立 IP（不同于 RK3588 的硬件连接）。
CSI DPHYInnosilicon combo PHY，4 data + 2 clock lanes。支持 1×4 full mode 或 2×2 split mode（split 需 GRF 寄存器配置，主线尚未支持）。
设备节点/dev/video0 (rkisp_mainpath), /dev/video1 (rkisp_selfpath), /dev/video2~6 (raw/stat/params), /dev/video7 (rkisp-statistics), /dev/video8 (rkisp-input-params), /dev/media0
Media拓扑imx415 (sensor) → csi2_rx (host) → rkisp_input → rkisp_mainpath → /dev/video0
VICAP 路径: sensor → csi2_rx_host → rkcif_mipi → /dev/videoX
# ISP pipeline setup (Radxa ROCK3 Model A, IMX219, mainline rkisp1) media-ctl -d "platform:rkisp1" \ --set-v4l2 '"rkisp1_isp":0 [fmt:SRGGB10_1X10/3280x2464]' media-ctl -d "platform:rkisp1" \ --set-v4l2 '"rkisp1_isp":2 [fmt:YUYV8_2X8/3200x2400]' # 主线内核源码路径 # drivers/media/platform/rockchip/rkisp1/ # drivers/media/platform/rockchip/rkcif/ (VICAP) # drivers/phy/rockchip/phy-rockchip-inno-csidphy.c

显示子系统 — VOP2 (Video Output Processor v2)

来源: RK3568 TRM Part2 Ch.44; Linux mainline drivers/gpu/drm/rockchip/
寄存器基址0xFE040000 (64KB)
窗口类型2×Cluster (AFBCD/YUV/RGB/Scaling/CSC/BCSH) + 2×ESmart + 2×Smart = 6 层叠加
Video PortVP0: 4K@60 (HDMI/eDP) · VP1: 2K (MIPI DSI) · VP2: 1080P (LVDS/DSI)
OverlayPre-Overlay → Layer_Mux (6层) → Main_Overlay (Alpha Blending) → Post_Overlay (背景色)
Post-ProcessBCSH (亮度/对比度/饱和度/色调) · Gamma校正 · 3D_LUT · HDR10/SDR互转
DRM对象Plane(Window) → CRTC(VP) → Encoder(HDMI/eDP/MIPI) → Connector → Panel
内核路径drivers/gpu/drm/rockchip/rockchip_drm_vop2.c · rockchip_drm_vop2_regs.h
# 板端 DRM 设备节点 /dev/dri/card0 ← DRM primary node /dev/dri/renderD128 ← DRM render node # OpenCV HighGUI 内部调用链 cv2.imshow() → HighGUI backend (GTK/Qt) → DRM/KMS → rockchip-drm (VOP2) → dw-mipi-dsi → LCD Panel

NPU 推理子系统

来源: RK3568 Datasheet V1.1 §1.2.2; RK3568 TRM Part2 NPU chapter; Rockchip RKNN SDK
NPU 硬件0.8 TOPS (datasheet) / 1.0 TOPS (marketing) @ INT8。支持 INT8/INT16/FP16/BFP16 混合运算。独立电源域 VD_NPU。
NPU 驱动CONFIG_ROCKCHIP_NPU · 内核驱动 v0.8.2 · /dev/rknpu
RKNN Runtimelibrknnrt.so v1.5.0 — 用户态运行时，封装 NPU ioctl 调用
rknn_server/usr/bin/rknn_server v1.5.0 — 板端守护进程，管理 NPU 资源分配
RKNNLite APIload_rknn(model.rknn) → init_runtime() → inference(inputs) → release()
模型格式.rknn — 预编译量化模型 (INT8), 从 ONNX/PyTorch/TF 通过 rknn-toolkit2 (PC端) 转换
YOLOv5 输出(1,255,80,80) stride=8 + (1,255,40,40) stride=16 + (1,255,20,20) stride=32
255 = 3×(80类别+4坐标+1置信度) = 3 anchors × 85
# NPU 软件栈 Application (Python) → rknn_toolkit_lite2 1.5.0 (Python RKNNLite class) → librknnrt.so 1.5.0 (/usr/lib/) → rknn_server (/usr/bin/) → NPU Driver v0.8.2 (CONFIG_ROCKCHIP_NPU) → RK3568 NPU Hardware @ 0xFD900000
