### 当前只需要理解这 4 条链

#### 1. 采集链

```text
IMX415 → MIPI CSI → RKISP → V4L2 → /dev/video0
```

回答：Camera 如何变成 Linux 设备节点？

#### 2. 图像转换链

```text
/dev/video0 → NV12 → GStreamer → videoconvert → BGR → OpenCV Mat
```

回答：为什么 `cv2.VideoCapture(0)` 失败，而显式 GStreamer pipeline 成功？

#### 3. 推理链

```text
OpenCV Mat → resize/letterbox → RKNNLite → RKNN Runtime → NPU → 后处理
```

回答：模型输入、推理输出、检测框和原图坐标之间是什么关系？

#### 4. 输出链

```text
检测结果 → MIPI 屏显示
检测结果 → FFmpeg 编码 → RTMP → Nginx → HLS → Windows 播放
```

回答：本地显示和网络推流为什么是两条不同的输出路径？
