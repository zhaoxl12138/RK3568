# Camera 求职知识库目录精简设计

## 目标

把当前知识库从“AI Camera / Python MVP 综合项目”收敛为“RK3568 + IMX415 Camera 驱动求职学习库”，让每天只需要从一个任务入口进入，并且不会再被 `01`～`05` 中已经过时的路线、环境说明和演示项目分散注意力。

## 设计原则

1. 当前学习主线只保留在 `06-任务`，不再维护第二套“主线目录”。
2. 原理和命令按领域保留在 `07-专项笔记`，但不承担当前进度管理。
3. 网页总图继续放在 `04-项目`，因为它们是当前 Camera 驱动链路的可视化教材。
4. 真实板端输出继续放在 `05-实验与证据`，因为面试复述必须能回到实测证据。
5. 已经掌握的环境说明和旧 AI/Python 路线直接删除，不移动到归档；Git 历史已经承担恢复职责。
6. 删除源文件时同步清理首页、任务看板、网页生成器、生成网页和反向链接，禁止留下“点进去不存在”的入口。

## 目录决策

| 目录 | 决策 | 原因 |
|---|---|---|
| `01-主线` | 整体删除 | 当前主线已经由一周计划和分章节学习文档承担，旧 AI/Python 路线会造成双入口 |
| `02-资料` | 整体删除 | 内容以旧 Buildroot/OpenCV/AI 链接为主；实际学习应在章节中按需引用具体资料 |
| `03-环境` | 整体删除 | WSL、VS Code 和 SDK 环境已经搭好，不应继续占据主导航 |
| `04-项目` | 保留 `10`～`16` 的 Phase0/IMX415 网页；删除 `00`～`03` 的旧 Markdown 项目文档 | 可视化页面是当前教材，旧 YOLO/Python 演示不是当前求职主线 |
| `05-实验与证据` | 保留两份 2026-07-28 Camera 实测记录；删除 `00`～`02` 旧入口/日报 | 板端证据有价值，旧 Buildroot 验机和 AI 日报已过时 |
| `05-实验与证据/实验产物` | 本轮暂留 | 多份 `07` 专项笔记仍引用这些图片和视频；直接删除会制造大批断链，后续清理旧 AI 专项时一并删除 |
| `06-任务` | 保留并作为唯一主线 | 当前周计划、第一章、第二章都在这里 |
| `07-专项笔记` | 本轮不整目录删除 | Camera/V4L2 和系统链路仍有复习价值；旧 AI 专项单独做下一轮内容清理 |
| `08-附录` | 保留 | 包含原理图资料索引和绘图规范，不是当前导航入口 |
| `09-输出沉淀` | 本轮保留 | `V4L2` 面试输出仍可用；其余旧 AI 输出下一轮再判断 |

        ↓

        ↓

## 验收标准

- `01-主线`、`02-资料`、`03-环境` 不再存在。
- `04-项目` 中只剩 Camera 驱动相关的 Phase0/IMX415 可视化文件。
- `05-实验与证据` 顶层只剩两份 Camera 实测文档；旧 AI 实验产物因现有引用暂留在子目录。
- 首页和任务看板只指向 Camera 驱动求职主线。
- 网页目录不再展示被删除的旧文档。
- 链接检查结果为 0 个断链、0 个活动文档指向归档。
- Node 测试全部通过。
