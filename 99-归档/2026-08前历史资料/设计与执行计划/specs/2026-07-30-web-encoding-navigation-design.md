# RK3568 学习站乱码修复与导航统一设计

## 目标

让仓库内的本地学习网页始终以 UTF-8 HTML 打开，任何站内内容入口都不再直接跳转原始 Markdown；同时用一套全站导航降低跨页面学习时的迷失感。

## 已确认的根因

- 扫描到的 42 个 HTML 均为有效 UTF-8，并在文档前部声明 `<meta charset="utf-8">`。
- 站内仍有 12 个链接直接指向 `.md`。浏览器对这些目标会按原始文件或受限制资源处理，不具备稳定的网页阅读体验。
- `build-dashboard.mjs` 只扫描驾驶舱首页和 `pages/` 第一层 HTML，未扫描 `04-项目` 的 Phase0/IMX415 页面，因此无法发现、生成和改写这些页面中的 Markdown 入口。
- 驾驶舱、生成笔记页和 Phase0 页面使用不同导航内容；`data-site-nav` 只是标记，没有形成统一的链接集合与当前页状态。

## 设计

### 1. 单一网页入口规则

- 站内学习内容只链接 `.html`。
- Obsidian 编辑入口使用 `obsidian://open`，不把 `.md` 当作网页。
- 主入口 Markdown 在网页中统一映射到驾驶舱首页。
- 构建器递归扫描仓库内有效 HTML，发现其引用的 Markdown，将目标加入生成目录并改写链接。

### 2. 共享全站导航

`site.js` 在页面加载时规范化所有 `[data-site-nav]`：

- 品牌入口：RK3568 Camera 学习站。
- 核心入口：首页、当前任务、学习路线、系统地图、Phase0、专项笔记、实验依据。
- 辅助入口：项目总览、开发环境、归档、在 Obsidian 中打开。
- 根据当前 URL 自动标记当前栏目。
- 展示当前学习阶段，但不把阶段写死在 HTML。

导航在桌面端固定于顶部；窄屏改为紧凑的两行结构和横向滚动，不遮挡正文。Phase0 页面原有的上一页/下一页和页面内学习顺序继续保留，作为局部导航，不与全站导航混用。

### 3. 生成笔记可读性

- 生成页继续保留单一 H1、正文卡片和 Obsidian 编辑入口。
- Markdown 图片语法生成真正的 `<img>`，不再退化为文本链接。
- 所有生成页保留 UTF-8、中文语言声明和响应式 viewport。

### 4. 验证

- 单元测试先复现“仓库其他目录中的 Markdown 链接没有生成 HTML”。
- 静态测试检查全部活动 HTML：UTF-8、charset、无替换字符、无 `.md` 内容链接、共享导航资源存在。
- 构建后检查所有相对链接目标存在。
- 浏览器抽查首页、Phase0、IMX415 三层调用图、生成的 SDK 源码笔记，以及窄屏导航。

## 非目标

- 不把现有静态站重写为 SPA。
- 不改变 Obsidian 作为知识源和编辑入口的定位。
- 不部署公网服务器。
- 不重构与本次乱码和导航无关的学习内容。
