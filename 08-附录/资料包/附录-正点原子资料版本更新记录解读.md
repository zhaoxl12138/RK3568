## 当前资料版本判断

从更新记录看，当前资料大概率是 `V7.2` 之后的整理版。

重要变化：

- `10、用户手册/02、开发文档` 在后续版本中发生过移动或整理。
- OpenHarmony 和 Ubuntu 系统镜像在 `V7.2` 中已经移除。
- `09、系统镜像` 改成分别压缩，减少单个镜像包过大的问题。
- Camera 开发例程、Linux5.10 AI 例程、交叉编译工具是后续版本新增的重点。

### V5.0：Camera 例程继续更新

重点：

- `Camera应用开发手册` 更新到 `V1.1`
- `Camera开发例程` 增加 Qt/QML Camera 示例
- Linux 驱动例程 Makefile 更新
- 静态 IP 文档新增

对我最有用的是 Camera 手册更新和静态 IP 文档。

### V7.1：Camera C++ 工程更值得看

重点：

- `01、程序源码/08、Camera开发例程/c++/CMakeLists.txt` 更新
- Linux 驱动例程更新
- 底板原理图更新到 `V1.7`
- 核心板引脚复用表更新

对我来说，`Camera开发例程/c++/CMakeLists.txt` 很关键，可以参考它做自己的 C++17/CMake 工程。

### V7.2：移除不相关系统，资料更聚焦

删除：

- Ubuntu-base 根文件系统
- OpenHarmony5.0 系统镜像
- Ubuntu 系统镜像
- Ubuntu 移植参考手册

这对当前路线反而是好事：我不需要分心做 Ubuntu/OpenHarmony 系统移植，主线回到 Buildroot、Camera、AI、推流。

## 容易误判的地方

- PDF 或更新记录里提到的 `02、开发文档`，当前实际目录里可能不存在或已移动。
- `OpenHarmony` 和 `Ubuntu系统镜像` 被移除，不是资料缺失，而是版本更新后的结果。
- `RTMP推流` 有资料，但我的项目目标仍然可以写成 RTSP/RTMP 扩展。
- AI 视频有 RV1126 内容，只能参考流程，不能照搬命令。
- Linux 4.19 和 Linux 5.10 的 AI 例程、SDK、镜像不要混用。
