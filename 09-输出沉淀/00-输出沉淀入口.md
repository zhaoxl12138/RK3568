# 00-输出沉淀入口

这里存放“学完以后能讲出来”的内容。

它和主线的区别：

```text
主线回答：我下一步学什么。
专项笔记回答：某个技术细节是什么。
输出沉淀回答：我能不能把它讲清楚。
```

当前优先级：

```text
未来一个月不追 YOLOv8、不追 C++、不追多路推流。
先把已经跑通的 Python MVP 背后的概念补齐，并沉淀成可讲解的专题。
```

## 输出标准

每篇专题至少回答：

- 这个模块解决什么问题。
- 它在当前 RK3568 项目里处于哪一段。
- 当前实测现象是什么。
- 如果它坏了，会表现成什么。
- 面试时怎么讲。
