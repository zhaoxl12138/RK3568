# RK3568 Camera 学习课程导航系统设计

## 目标

把当前 45 个有效 HTML 从“资料展示站”重构为一条可连续学习的课程路线。用户打开首页后，应在 5 秒内知道：当前学到哪里、下一步是什么、完整路线有哪些、在哪里验证。

## 现状盘点

- 有效 HTML：45 个。
- 站点壳与自动生成笔记：35 个，位于 `00-首页/学习驾驶舱`。
- 手工可视化页面：10 个，位于 `04-项目`。
- 所有页面已经加载共享 `site.js` 与 `site.css`，适合用共享组件统一导航。
- 当前导航仍以“当前任务、系统地图、Phase0、专项笔记、实验依据”等资料类别组织。
- 当前路线是旧的阶段 0–10，和新的 00–11 课程主线不一致。
- 仓库包含大量用户既有改动和旧页面删除状态；本次重构不恢复、不覆盖这些改动。

## 推荐架构

采用“课程数据单一来源 + 共享脚本增强 + 现有页面复用”。

1. 在 `site.js` 中维护唯一的 00–11 课程表：名称、页面、学习目标、状态。
2. 所有页面的顶部导航由共享脚本统一渲染，只保留“学习首页、课程路线、课程目录、资料与实验、当前阶段”。
3. 主线页面自动注入当前位置、12 阶段进度、上一阶段、下一阶段和底部课程导航。
4. 首页只显示当前阶段、当前目标、下一步和完整路线；资料入口收拢到次级区域。
5. 学习路线页按 00–11 展示唯一顺序，不再把“Phase0 阶段”和“知识模块”混合使用。
6. 未进入主线的页面继续保留，通过“资料与实验”访问；零入链生成页只列为归档候选，本轮不删除。

选择这一方案的原因：

- 不需要新增 12 个空壳课程页。
- 不需要手工修改 45 份页面的相同导航结构。
- `file://` 与本地 HTTP 都能工作，不依赖 React、Vue 或服务端。
- 后续学习完成一个章节时，只需更新课程表的目标页面和状态。

## 统一导航组件

### 顶部全站导航

- 品牌：RK3568 Camera 课程。
- 学习首页。
- 完整路线。
- 课程目录：展开后显示 00–11。
- 资料与实验：系统图、实验依据、专项笔记、开发环境、可视化参考、归档。
- 当前阶段：04 MIPI CSI-2 / D-PHY。

### 主线页面课程上下文

顶部自动插入：

- `当前位置：阶段 NN / 名称`
- 上一阶段和下一阶段。
- 00–11 紧凑进度条，已完成、当前、待学习有不同状态。

底部自动插入：

- `← 上一阶段`
- `返回完整学习路线`
- `下一阶段 →`

参考页面不显示上一课/下一课，避免把补充材料误认为主线。

## 首页信息结构

首页只保留四个核心区块：

1. 当前阶段：04 MIPI CSI-2 / D-PHY。
2. 当前目标：能从 DTS endpoint、D-PHY 驱动和 `media-ctl -p` 解释 Sensor RAW 数据如何进入 CSI/RKISP。
3. 下一步：进入阶段 04 页面。
4. 完整路线：00–11 线性课程表。

“实验依据、专项笔记、开发环境、可视化总图、归档”放进一个次级参考区，不再与主线竞争视觉优先级。

## 页面模板策略

共享脚本只负责课程外壳，不批量改写正文。主线正文在后续章节学习完成时，逐步按以下结构收敛：

1. 为什么学习
2. 核心概念
3. RK3568 实际对应
4. 代码 / DTS 位置
5. 实验验证
6. 命令输出
7. 常见问题
8. 面试表达
9. 下一步

当前已有页面内容继续保留，避免机械重排破坏已经完成的图和笔记。

## 链接与兼容性

- 所有链接通过课程表相对于站点根目录生成。
- 同时支持 `file://` 和 `http://127.0.0.1`。
- 不使用模块脚本、`fetch()`、React 或 Vue。
- 保留静态 HTML 中已有导航作为无 JavaScript 回退；JavaScript 启动后替换为统一课程导航。
- 删除或归档前必须通过入链统计和全站链接检查。

## 测试与验收

- 课程表必须正好包含 00–11，路径唯一且目标存在。
- 首页必须出现当前阶段、当前目标、下一步和完整路线。
- 每个主线页面必须被共享运行时识别，并生成当前位置、进度条和上下阶段导航。
- 参考页面不能错误显示课程上下阶段。
- 所有有效 HTML 必须 UTF-8、不得直链 Markdown、内部资源可解析。
- 全量 Node 测试、知识库链接检查和浏览器桌面/窄屏检查通过后才能宣告完成。

## 明确不做

- 本轮不删除 5 个归档候选。
- 本轮不把全部 26 个参考页面重写成统一教程正文。
- 本轮不引入前端框架、数据库或服务器依赖。
- 本轮不恢复仓库中已经被用户删除的旧目录和旧页面。
